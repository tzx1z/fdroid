# inkov.dev F-Droid repository

This is the F-Droid repository of developer Evgeny Inkov
(me@inkov.dev, xmpp:tzx1z@inkov.dev, https://inkov.dev).
The APKs are built reproducibly from public source code and signed by the author.

The repository is published at https://fdroid.inkov.dev via GitHub Pages.
The repository keeps only the latest version of each app, older versions are
on the app's GitHub releases page.

## Add the repository

[Add to F-Droid](https://fdroid.link/#https://fdroid.inkov.dev/repo?fingerprint=1B4D3D289AC970F53860490E7AAA8B40E8810DFA149E3CA66FB93FB18E5738CE)
